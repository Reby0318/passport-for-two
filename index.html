How this page is hosted

It is a real website

Claude wrote this page as one HTML file and published it to Anthropic's servers. Opening the link downloads the page from there, the same way any website works. That's why it opens on anyone's phone.

Someone pays for serving it

Storing the file and sending it to every visitor costs storage and bandwidth. Anthropic covers that as part of the Claude plan, the way Google Drive hosts your files.

Moving it to our own address

The page lives on claude.ai, not on a domain we own. To give it our own address, upload the same HTML file to GitHub Pages or Netlify (free for a page like this) and add a domain for about $10–15 a year.
