How this page is hosted

It is a real website

This page is one HTML file. Opening a link downloads that file from a server, the same way any website works. That's why it opens on anyone's phone.

Someone pays for serving it

Storing the file and sending it to every visitor costs storage and bandwidth. On claude.ai, Anthropic covers that as part of the Claude plan. On GitHub Pages, GitHub covers it for free, as it does for small static sites.

It has two homes

The same file is served from claude.ai/artifact/FJWiFZ5UAmj1P2YSoApeYZ and, for free, from reby0318.github.io/passport-for-two. A custom domain like ourtravelcomic.com would only add about $10–15 a year.
